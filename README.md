# 1000 → 60K — 30-Day Trading Tracker

A mobile-first educational projection, planning and journaling web app.

## Features
- 30-day mathematical compounding plan
- 1–5% daily scenario comparison
- Compound calculator
- Per-trade compound scenario calculator
- 10 AM–5 PM workflow checklist
- Trade journal
- LocalStorage persistence
- Responsive dark UI

## Run
Open `index.html` in a browser.

## GitHub Pages
Create a GitHub repository, upload the files, then enable:
Settings → Pages → Deploy from branch → main / root.

## Important
This project is an educational calculator/tracker. It does not guarantee trading returns or recommend a trading strategy.
